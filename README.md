# 🐾 Animal Shelter Finder

## 📖 Description

Animal Shelter Finder is a simple web application that helps users search for animal shelters by entering a ZIP code.

Users enter their ZIP code and click the **Find Shelter** button to search for nearby animal shelters. This project was created to practice working with APIs, JavaScript, and displaying information dynamically on a webpage.

## ✨ Features

- Search for animal shelters using a ZIP code.
- Display shelter search results.
- Simple and user-friendly search interface.
- Retrieve shelter information using an API.

## 🛠️ Tech Stack

- **HTML5** – Structures the webpage, input field, button, and shelter results section.
- **CSS3** – Styles the webpage, background image, and search interface.
- **JavaScript** – Handles user input, button clicks, API requests, and displaying results.
- **API** – Retrieves animal shelter information based on the user's search.

## 🧠 What I Learned

- How to use JavaScript `fetch()` to request data from an API.
- How to retrieve and work with JSON data.
- How to use event listeners to handle button clicks.
- How to capture user input from an HTML form.
- How to dynamically display API results using the DOM.

## 🚀 How to Use

1. Visit the [Live Website](https://apipets.netlify.app/).
2. Enter a ZIP code in the search field.
3. Click **Find Shelter**.
4. View the animal shelter search results.

## 💻 How to Install

1. Clone the GitHub repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser or using Live Server.
4. Enter a ZIP code and click **Find Shelter**.
